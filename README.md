# PredIQ Android

Native Android client for [getprediq.site](https://getprediq.site), built with Kotlin and Jetpack Compose. The app consumes the standalone PredIQ Intelligence API and follows the shared PredIQ light-mode design system.

## Core surfaces
- Today / Upcoming intelligence
- Live analysis with explicit live, cached, no-opportunity and error states
- Results & accuracy
- Account, subscription and mobile-money checkout
- Match Intelligence deep dive
- League Winner forecasts

PredIQ probabilities are estimates, not guarantees. Bet responsibly and comply with local laws.

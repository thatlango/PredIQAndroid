# PredIQ Android UI/UX Sprint 3

This branch reconciles the estate-wide Tuku UI/UX standard with the current PredIQ Android sports-media work instead of reverting the newer experience.

## Release intent
- preserve the current sports-intelligence information architecture and media work
- use neutral surfaces for most of the product and reserve strong colour for meaning
- preserve the dark/lime live mode as a deliberately higher-attention environment
- standardise typography, semantic states, radii and Material 3 component geometry
- enforce a 44dp minimum and 48dp preferred handheld interaction target through shared tokens
- keep current loading, cached, service-error, no-opportunity and retry behaviour intact

## Follow-on screen tranche
The next screen-level pass will use these tokens to further simplify Today, Live, Explore, Results and Account without reducing backend capability or evidence visibility.
